# 不变量

后续改动不能破坏这些行为。

1. 应用是本地优先的 Windows 桌面应用。SQLite 保存结构化数据。图片在 `%APPDATA%\wardrobe\images\`。ONNX 在本机运行，不依赖 Python、云服务或网络。

2. 衣物图片有两种角色。`garment` 是衣物照，可以作为主图和穿搭素材。`tag` 是吊牌照，不能作为封面，也不能参与穿搭拼图。

3. 图片处理有三套坐标：原始图片像素、处理后缩放图片、Flutter 界面显示。点选、擦除、填补、预览和保存使用同一套转换，不在各组件里各自近似。

4. 穿搭封面：`coverMode = photo` 用全身照，`coverMode = collage` 用衣物拼图。删掉其中一种后，按剩余内容回退。

5. 一套穿搭里同一件衣物只出现一次。同一套穿搭在同一天只挂一次。同一分类的同级顺序保持稳定。

6. OCR 和颜色识别只填充空字段或给出建议。用户已经填写的内容优先保留。

7. 已发布的 schema 迁移不重写。新版本只追加迁移步骤。升级必须可重复执行，且不丢已有数据。
