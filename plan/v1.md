# 衣橱 v1

Windows 桌面电子衣橱。本文是 **v1 总览**（已做到 v1.5，不再往这里加新功能）。v2 见 [v2.md](v2.md)。分期快照是 `v1.1-…`～`v1.5-…` 以及 `outfit-parity-todo.md`。

启动见 [docs/run-windows.md](../docs/run-windows.md)；发给没装 Flutter 的电脑见 [docs/package-windows.md](../docs/package-windows.md)。数据在 `%APPDATA%\wardrobe\`（SQLite + 图片）。改过数据库结构后必须**完全重启**，热重载不够。

---

## 产品设想

一套 Flutter 代码。第一期只跑 Windows，不是网页。以后加 Android/iOS 时复用数据层和业务，**单独做手机布局**。

视觉先贴近 [reference/简衣橱](../reference/简衣橱)（白底、蓝紫强调色、圆角卡片），桌面信息架构是左侧导航 + 右侧内容，不照搬手机底栏。更细的美化放到功能可用之后，再用 pen.dev 出高保真稿再改 Flutter。

数据本地 Drift / SQLite，图片复制到应用目录。仓储层预留同步接口，第一期不接账号/云。穿搭第一期是「一张效果图 + 元数据」，不是从衣橱里挑多件拼一套。

## 现在能做什么

### 壳

- 左侧：衣橱 / 穿搭 / 日历
- 右侧主区；窗口按桌面用（约 1100×720 起）
- 没有「我的」、会员、云同步入口

### 衣橱

- 根分类卡片：子树封面 + 件数；点进去一律进分类页（空也不跳添加）
- 右上角「分类管理」：改名、同级上移/下移、增删、新增大分类（可选测量模板）
- 大分类下最多两层小分类（例如 `上装 / 卫衣 / 兜帽卫衣`）
- 「无分类」可改名、排序，不能删
- 同一层名称不能重复；不同父分类下可以同名；提示「同一层已有「某某」」
- 删除子树：衣物回到直接上一级；删大分类才回无分类；确认弹窗写出实际去向
- 分类页：子分类卡片 + 本层衣物；可「添加子分类」并勾选本层衣物移入；「恢复默认封面」；FAB 添加带当前分类
- 封面：自定义仍在子树内则用它，否则该子树 `createdAt` 最新一件；同一件可当祖先+自己的封面，不能当旁系封面
- 单品：本地选图（一张一单品）→ 详情（只读）→ 修改；删除在修改页
- 详情顶栏「移动」弹出整棵分类树；封面图上不叠移入/移出；可按路径勾选「设为封面」
- 编辑：完整路径选分类；尺码模板跟根大分类；包包/配饰管理页模板叫「物件」，表单测量项叫「尺寸」
- 字段：类别、款式、颜色、季节、面料、品牌、价格、尺码、购入时间、购买信息、存放位置、标签、备注（括号例子全部手填）
- 搜索：本地过滤（含分类路径），结果按添加时间新→旧
- 分类页列表可按添加/购买/修改时间、价格排序（方向可切）；只记本次运行，不写磁盘
- 默认种子：无分类、内衣、上装、下装、鞋子、包包、配饰

### 穿搭

- 与衣橱同一套分类树（同一张 `categories` 表，`kind = outfit`）
- 种子：无分类、工作、休闲、派对、运动、度假
- 首页、分类管理、浏览、封面、移动、同名、删除回上级：规则与衣橱相同
- 新增大分类**没有**测量模板；编辑页没有尺码 / 「物件 / 尺寸」
- 一张效果图 + 名称、季节、备注；不是多件拼套
- 搜索按添加时间新→旧；分类页可按添加/修改时间排序

### 日历

- 月视图、今天、前后月、选中日期、农历小字
- 「点击添加记录」「筛选」提示后续开放，不写穿着记录

### 工程与发布

- Flutter Windows、Riverpod、go_router、Drift、file_picker
- 库 schema 当前为 **4**（1 初版 → 2 封面 → 3 衣橱分类树 → 4 穿搭场合种子）
- 可打 Windows 发行目录 / zip，整夹拷贝即可；需要 VC++ x64 可再发行组件

## 明确不做（v1 范围外）

这些曾写进设想，但**不是当前 v1 要做的**：

- 「我的」、会员、意见反馈、分享、使用帮助
- 账号、云同步（接口可留，不要写上传）
- 拍照 / 从相册批量添加（桌面继续文件选择，一张一单品）
- 穿搭画布（从衣橱挑多件组一套）
- 分类拖拽（现在用上移/下移）
- 手机布局、手机底栏、Flutter Web
- 覆盖本文之前的旧计划原文（那些文件保持快照）
