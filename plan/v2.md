# 衣橱 v2

Windows 桌面电子衣橱。本文是 **v2 总览**：在 v1 之上要做的图像处理与多图。v1 已实现内容见 [v1.md](v1.md)，不要改 v1.1–v1.5 归档。

当前产品版本：**v2.1**（进行中）。

启动见 [docs/run-windows.md](../docs/run-windows.md)。数据在 `%APPDATA%\wardrobe\`。改过数据库结构后必须**完全重启**，热重载不够。

---

## 这一期要解决什么

v1 是「一张图 + 手填字段」。v2 在**新增/修改衣物**时处理照片：

1. 同一件衣物可以有多张图。
2. 新增时先在图片工作室处理照片，再填字段。

分类识别（MobileNetV2 / 「这是衬衫」）**先不做**，类别继续手填。吊牌 OCR **不做**，这条添加流程也不再区分吊牌照。

---

## 处理流程（衣物照）

用户选图 → 缩放（长边 ≤ 1600，并按 EXIF 转正，**原图整张保留**）→ U²-Net-p 自动抠图得到整张 Mask 和透明 PNG → 按 Mask 收紧裁剪抠图（不裁原图）→ 从前景记下中文色名和 RGB 基准色 → 用户在**抠图结果**上点选精修（左键点衣服、右键点衣架），MobileSAM 用点重算整张 Mask（可撤回、可放大）→ 填信息后保存。

不接 Python、不接云、不加 Flutter 插件。U²-Net-p ONNX（约 4.7 MB）和 MobileSAM encoder/decoder ONNX（约 40 MB）打进资源；Windows 用 ONNX Runtime CPU DLL（`onnxruntime.dll`）经 FFI 推理。颜色用前景像素直方图，不另装 OpenCV。

## 现在做到哪

### 多图

- 一件衣物多张照片；一张设为封面（列表、分类封面仍读 `clothing_items.imagePath`）
- Windows 选图可多选；图片工作室可增删、设封面、原图/抠图、重新处理、点选精修
- 新增：先全页处理图片，再「下一步」填表；修改：表单上点缩略图进同一间工作室
- 详情页可切换多图；透明抠图衬棋盘格

### 预处理

- 长边缩到 1600，EXIF 转正；`originalPath` 存整张缩放图
- U²-Net-p 抠图：透明 PNG + 灰度 Mask；抠图可按 Mask 收紧，原图不跟着裁
- 精修：对着整张抠图结果点选。左键正点（衣服）、右键负点（衣架/背景）；Encoder 对这张图只跑一次，之后每次加点只跑 Decoder，并用新 Mask **整张替换**。可撤回最后一个点；滚轮放大，中键或空格拖动
- 第一遍仍可能带衣架；衣服和衣架上各点一下后，Mask 应只留下衣服
- 抠图失败则保留缩放后的原图，不挡保存

### 颜色

- 只统计 Mask 内像素，聚成中文色名 + 占比（白、黑、灰、红、橙、黄、绿、青、蓝、紫、粉、棕、米）
- 第一遍抠图另存衣服 RGB 基准色（写进 `colorJson`）
- 颜色栏为空时自动填入；已有字时只提示「填入识别颜色」
- 类型 / 款式不自动填

### 明确后做

- [ ] 吊牌 PaddleOCR / RapidOCR：品牌、尺码、材质（与抠图流程分开，以后再说）
- [ ] 衣服类型分类模型
- [ ] 精修画笔硬擦（点选不够时再加）
- [x] 手动精修（v2.1：先框选按颜色，后改为 SAM 点选）

## 数据

库 schema **5**（v1 是 4）。

新表 `clothing_item_images`：原图、抠图、Mask、角色、是否封面、该图颜色 JSON。旧数据把原来的 `image_path` 迁成一张「衣物」主图。

列表和封面仍用 `clothing_items.imagePath`（有抠图则用抠图），避免改分类树逻辑。

图片仍在 `%APPDATA%\wardrobe\images\`。模型在安装包 `assets/models/`（`u2netp.onnx`、`mobile_sam_encoder.onnx`、`mobile_sam_decoder.onnx`），首次运行可拷到 `%APPDATA%\wardrobe\models\`。
