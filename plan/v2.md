# 衣橱 v2

Windows 桌面电子衣橱。本文是 **v2 总览**：在 v1 之上要做的图像处理与多图。v1 已实现内容见 [v1.md](v1.md)，不要改 v1.1–v1.5 归档。

当前产品版本：**v2.2**（吊牌 OCR，见 [v2.2.md](v2.2.md)）。v2.1 精修快照见 [v2.1.md](v2.1.md)。

启动见 [docs/run-windows.md](../docs/run-windows.md)。数据在 `%APPDATA%\wardrobe\`。改过数据库结构后必须**完全重启**，热重载不够。

---

## 这一期要解决什么

v1 是「一张图 + 手填字段」。v2 在**新增/修改衣物**时处理照片：

1. 同一件衣物可以有多张图。
2. 新增时先在图片工作室处理照片，再填字段。

分类识别（MobileNetV2 / 「这是衬衫」）**先不做**，类别继续手填。吊牌 OCR 见 [v2.2](v2.2.md)。

---

## 处理流程（衣物照）

用户选图 → 缩放（长边 ≤ 1600，EXIF 转正，**原图整张保留**）→ 自动进精修 → **点选** MobileSAM 定外形（左键衣服、右键衣架）→ **笔擦**（可选保护衣服色）→ **取样再涂抹填补** → 从 Mask 记颜色 → 填信息后保存。

加图不自动跑 U²-Net。U²-Net-p 仍在资源里，供工作室「重新处理」。

不接 Python、不接云、不加 Flutter 插件。U²-Net-p、MobileSAM、PP-OCRv4 检测/识别 ONNX 打进资源；Windows 用 ONNX Runtime CPU DLL（`onnxruntime.dll`）经 FFI 推理。颜色用前景像素直方图，不另装 OpenCV。

## 现在做到哪

### 多图

- 一件衣物多张照片；一张设为封面（列表、分类封面仍读 `clothing_items.imagePath`）
- Windows 选图可多选；图片工作室可增删、设封面、原图/抠图、重新处理、点选精修
- 新增：先全页处理图片，再「下一步」填表；修改：表单上点缩略图进同一间工作室
- 详情页可切换多图；透明抠图衬棋盘格

### 预处理与精修

详见 [v2.1.md](v2.1.md)。

- 长边缩到 1600，EXIF 转正；`originalPath` 存整张缩放图
- 加图后直接点选；至少 1 个正点后才开放擦除/填补
- 点选：Encoder 对这张图只跑一次，加点只跑 Decoder，新 Mask 整张替换；可撤回；滚轮放大，中键或空格拖动
- 擦除：笔刷 + 可选保护衣服色
- 填补：笔选取样，再笔涂目标；只改笔触像素
- 抠图失败则保留缩放后的原图，不挡保存

### 颜色

- 只统计 Mask 内像素，聚成中文色名 + 占比（白、黑、灰、红、橙、黄、绿、青、蓝、紫、粉、棕、米）
- 颜色 JSON 写进该图的 `colorJson`
- 颜色栏为空时自动填入；已有字时只提示「填入识别颜色」
- 类型 / 款式不自动填

### 吊牌

详见 [v2.2.md](v2.2.md)。工作室可另加吊牌照；点选去背景后 RapidOCR；建议填入品牌、面料、尺码测量。吊牌不能当封面。

## 数据

库 schema **6**（v2.1 是 5）。`clothing_item_images.ocrJson` 存吊牌原文和解析出的品牌/面料/尺码。

表 `clothing_item_images`：原图、抠图、Mask、角色、是否封面、该图颜色 JSON、OCR JSON。旧数据把原来的 `image_path` 迁成一张「衣物」主图。`role` 为 `garment` / `tag`；吊牌不能当封面。

列表和封面仍用 `clothing_items.imagePath`（有抠图则用抠图），避免改分类树逻辑。

图片仍在 `%APPDATA%\wardrobe\images\`。模型在安装包 `assets/models/`（U²-Net-p、MobileSAM、PP-OCRv4 det/rec 与字典），首次运行可拷到 `%APPDATA%\wardrobe\models\`。
