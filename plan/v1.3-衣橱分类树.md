# v1.3：衣橱分类树

> 产品 **v1** 快照。总览见 [v1.md](v1.md)。下文是 2026-09-16 原文，不要覆盖。

## 做了什么

- 衣橱首页去掉排序按钮，右上角改为「分类管理」。搜索结果仍按添加时间新→旧。
- 衣橱分类入库（Drift `categories`）：改名、同级上移/下移、增删。
- 大分类下最多两层小分类，例如 `上装 / 卫衣 / 兜帽卫衣`。
- 点分类：有内容则进入「子分类卡片 + 直接挂在这一层的衣物」；全空则去添加。（v1.4 改为空分类也进详情页）
- 封面和件数按子树计算。删除分类时子树一起删，衣物回到「无分类」。（v1.4 改为有上级则回到上一级）
- 「无分类」可改名、排序，不能删。
- 单品编辑用完整路径选分类；尺码模板取根大分类。

## 本轮明确不做

- 穿搭分类树（见对齐待办）
- 分类拖拽（先用上移/下移）
- 云同步

后续细化见 [v1.4-分类细化.md](v1.4-分类细化.md)。
