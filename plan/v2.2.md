# v2.2：吊牌照与 RapidOCR

> 产品 **v2.2** 快照（2026-09-21）。总览见 [v2.md](v2.md)。抠图精修见 [v2.1.md](v2.1.md)。

在衣橱新增/修改衣物时，可另加吊牌照片：点选去掉背景，本机 RapidOCR 识别文字，建议填入品牌、面料、尺码。

```
添加衣物 → 图片工作室
              ├─ 衣物照：点选 / 擦除 / 填补（v2.1）
              └─ 吊牌照：点选去背景 → RapidOCR → 建议填入字段
         → 填表保存
```

OCR 用 **RapidOCR ONNX**（现有 `onnxruntime.dll` FFI），不依赖系统中文语言包。不接云、不接 Python、不加 Flutter OCR 插件。

---

## 照片

- 工作室可再加吊牌照（可多张、可选）。写入已有 `ItemPhotoRole.tag`，**不能设封面**；列表仍用衣物主图。
- 缩放与衣物照相同（长边 ≤ 1600，EXIF 转正）。
- 去背景：**复用点选精修**（左键吊牌、右键背景）。不跑填补。擦除可留，方便抠掉手指/杂物。U²-Net 不做吊牌主路径（文字孔洞容易被挖穿）。
- OCR 在抠完的紧裁图上跑；抠失败则退回缩放原图仍尝试。

## 识别与存储

- 模型：PP-OCRv4 检测 + 识别 ONNX + 字典，打进 `assets/models/`，首次拷到 `%APPDATA%\wardrobe\models\`。经现有 `garment_onnx.cpp` 会话表加载；Dart 侧新模块（如 `lib/core/vision/tag_ocr.dart`）。
- 库升 **schema 6**：`clothing_item_images` 增加 `ocrJson`（原文、行框、解析出的品牌/面料/尺码）。衣物表字段仍手填为主。
- 解析用规则（成分、洗标、S/M/L、170/88A 等），不接大模型。
- 表单像颜色那样：空则建议填入；已有字只出「识别：… / 填入」。写入 **品牌、面料、尺码测量**。原文可在详情展开，不覆盖用户已填内容。

## 明确不做

- 云 OCR、Python、Flutter OCR 插件
- 用吊牌当分类封面
- 自动改「类别 / 款式」（类型模型仍后置）
- 穿搭板块
