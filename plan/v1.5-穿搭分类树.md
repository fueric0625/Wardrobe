# v1.5：穿搭分类树

> 产品 **v1** 快照。总览见 [v1.md](v1.md)。下文是 2026-09-20 原文，不要覆盖。

## 做了什么

- 场合分类写入同一张 `categories` 表（`kind = outfit`，schema 4）。种子 id 仍是：无分类、工作、休闲、派对、运动、度假。「无分类」可改名、排序，不能删。
- 穿搭首页去掉排序，右上角改为「分类管理」。搜索仍按添加时间新→旧。
- 分类管理、最多两层小分类、同级不重名、删除回上级：与衣橱同一套 `CategoryRepository`（按 `kind`）。新增大分类不出现测量模板。
- 点分类一律进详情页；可添加子分类并勾选当前层穿搭移入。
- 每级独立封面、详情按路径设为封面、顶栏树状「移动」。
- 编辑页用完整路径选分类。不抄衣橱尺码 / 「物件 / 尺寸」。

## 本轮明确不做

- 分类拖拽
- 云同步
- 日历
