# 工程计划 v1.0.11

侧栏底部的字体按钮改为设置入口。设置页先做字体、文字大小、主体颜色，页面按区块排列，以后可以再加区块。

不新建 `lib/ui`。外观数值放在 `lib/core/design_system`，设置页放在 `lib/app`。`lib/widgets` 仍是共用格子和拼图，不保存设置。

## 外观

一份外观包含三项，写在 `%APPDATA%\wardrobe\appearance.json`。没有这个文件时，先读已有的 `font.txt`，已选字体保持不变。

- 字体：沿用现有五款 Windows 字体。未知名称回到等线。设置里的「微软雅黑」用 `Microsoft YaHei`，不用 UI 版。等线没有「橱」，缺字只从微软雅黑补；UI 版字号比例不同，混用会让这个字小一号。已经存过的 `Microsoft YaHei UI` 读入时改成 `Microsoft YaHei`。
- 文字大小：小、标准、大、特大。通过 `TextScaler` 作用到现有文字。
- 主体颜色：固定几档，第一档是现在的蓝。浅色底由主色算出。

`buildAppTheme` 接收整份外观。主色和浅底从主题读取，替换各页面里写死的 `AppColors.primary` 和 `AppColors.primarySoft`。背景、文字、边框保持现在的中性色。

## 入口

侧栏底部是齿轮和「设置」，进入 `/settings`。这条路由挂在现有侧栏壳里。人在设置页时，衣橱、穿搭、日历都不显示为选中。

设置页第一块是「外观」。点选即保存并立刻生效。这一版不放空功能。
