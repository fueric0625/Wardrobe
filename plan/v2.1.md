# v2.1：图片工作室与精修

> 产品 **v2** 快照。总览见 [v2.md](v2.md)。下文是 2026-09-21 原文，不要覆盖。下一步吊牌 OCR 见 [v2.2.md](v2.2.md)。

## 做了什么

新增/修改衣物时先在图片工作室处理照片，再填表。一件可多图；一张设为封面。选图可多选。详情可切换多图，透明抠图衬棋盘格。

```
选图 → 缩放（长边 ≤ 1600，EXIF 转正，原图整张 JPEG）
    → 自动进精修
    → 点选 SAM 定外形
    → 笔擦（可选保护衣服色）
    → 取样再涂抹填补
    → 填表保存
```

加图只缩放，**不自动跑 U²-Net**。`originalPath` 存整张缩放图，不裁原图。U²-Net-p 仍在资源里，工作室「重新处理」才会用。

**点选**：左键衣服、右键衣架。Encoder 每张图一次，之后加点只跑 Decoder，新 Mask **整张替换**。至少 1 个正点后才开放擦除/填补。可撤回；滚轮放大，中键或空格拖动。

**擦除**：笔刷抠杂色；默认跳过衣服色，可关掉保护后硬擦。

**填补**：先在花纹上涂一笔取样（不上图），再涂要补的位置。只改笔触盖住的像素，不再自动找附近的洞，也不再按色差替换。

**阴影**：`eraseDarkerShadows`（`lib/core/vision/shadow_heal.dart`）仍在仓库并写了接回说明，**未接入流程**（深色印花、褶皱会被一起挖掉）。

**颜色**：只统计 Mask 内像素，聚成中文色名 + 占比。颜色栏为空时自动填入；已有字时只提示「填入识别颜色」。类型 / 款式不自动填。

抠图失败则保留缩放后的原图，不挡保存。

## 约束与数据

不接 Python、不接云、不加 Flutter 插件。Windows 用 `onnxruntime.dll` FFI。模型：`u2netp.onnx`、`mobile_sam_encoder.onnx`、`mobile_sam_decoder.onnx`。

库 schema **5**。表 `clothing_item_images`：原图、抠图、Mask、角色、是否封面、该图颜色 JSON。`role` 已有 `garment` / `tag`，**新图一律 `garment`**。列表封面仍读 `clothing_items.imagePath`。
